Light and dark

Wallpapers

Three wallpapers, drawn for it.

Each comes as a light and a dark picture, and the shell swaps them when the theme changes. Your own pairs work the same way: name them name-light.jpg and name-dark.jpg.

What's in it

Everything a desktop needs, nothing it doesn't.

Top bar

The focused app, the current workspace's windows left to right (click, scroll or drag to reorder), tray, status and clock.

Dock

Pinned and running apps with workspaces stacked the way niri stacks them. Hides when a window would cover it.

Control Center

Wi-Fi and Bluetooth with lists to connect, Focus, dark mode, night light, power mode, brightness, volume, now playing.

Search

Apps and open windows in one field. An app that is already open is switched to. >cmd runs a command, =1+2 calculates.

Settings app

Appearance, wallpaper, dock, displays with a 15-second "keep changes?", integrated / hybrid / dGPU graphics, battery charge limit, sound.

Liquid Glass, done properly

A rim of light on the edges that face it and a hair of shadow on the others, over a blurred, saturated wallpaper with smooth corners.

Notifications, OSD, lock

Notification bubbles, a calendar with history, volume and brightness under their menu-bar icons, a lock screen and password prompts.

Light on the laptop

QML on Quickshell; about 4% CPU at idle. On hybrid laptops the desktop renders on the integrated GPU so the dGPU can sleep.

Install

Two commands, then log in.

# Arch Linux
sudo pacman -S --needed niri xwayland-satellite quickshell \
  brightnessctl playerctl swayidle cliphist fuzzel wlsunset
git clone https://github.com/hangsiahong/ansai-shell
cd ansai-shell && ./install.sh

Log out and pick Niri in the login screen's session menu. Your old desktop stays there too. Edits to the QML reload live, so you can keep changing the shell while you use it.
